# CHKPT — Essayer les nouveautés du 9 novembre

Ce complément décrit les nouveautés. Les guides PDF/PPTX du 5 novembre restent une photographie de l’ancienne version ; certaines pages de Carte, profil et partage y sont dépassées.

1. **Carte** : ouvrir Outils carte. Utiliser Mon radar, puis Voir les lieux affichés. Les symboles indiquent le type de lieu ; ✓ vert = vérifié, ? gris = non vérifié. Le halo rouge signifie sponsorisé, sans garantir la vérification. Les exemples de sponsoring sont fictifs. La liste des lieux dans Outils carte permet de choisir un repère superposé.
2. **Check en attente** : en simulation privée autorisée, ouvrir GPS → Position du check → Simulateur, puis choisir « Cocody (Hôtel Horizon · fictif) ». Fermer les commandes si nécessaire, ouvrir ＋ → Faire un check, sélectionner l’hôtel et Confirmer le check. Il est enregistré avec 0 XP et apparaît dans Menu → Historique privé, sous les checks en attente. Une publication reste facultative. Un refus de distance ou une visite déjà enregistrée aujourd’hui ne donne aucun XP.
3. **Vérification opérateur** : seul l’animateur autorisé ouvre Réglages → Console opérateur → Lieux. Vérifier le lieu et confirmer la décision. Les preuves admissibles sont créditées une fois ; une anomalie reste à examiner. L’utilisateur reçoit une notification privée et retrouve ses XP sans refaire son check. Ne pas utiliser cette console pour expérimenter sur une base personnelle sans sauvegarde.
4. **Stories et Messages** : ouvrir la story d’un profil avec lequel les messages sont autorisés. Répondre dans le champ en bas ; la conversation privée s’ouvre avec la référence. Après 24 heures, le texte reste dans Messages, mais le média de la story expirée n’est plus accessible.
5. **Publication partagée** : Partager cette publication permet de l’envoyer dans Messages ou de la republier dans son fil. Le repost indique l’auteur et ouvre la source ; aucune copie de ses fichiers ou de ses réactions. Une source supprimée, bloquée ou devenue privée devient indisponible.
6. **Badges du profil** : Menu → Badges et progression → Choisir mes badges de profil. Choisir jusqu’à trois badges déjà acquis et leur ordre, ou rétablir la sélection automatique. Sur le profil, les symboles sont à droite de la localisation ; toucher un symbole pour son nom. Les visiteurs ne voient pas vos XP totaux.
7. **Photos et vidéos** : dans une publication contenant plusieurs médias, glisser horizontalement ou toucher les points. Sur ordinateur, les flèches du clavier fonctionnent quand le carrousel est sélectionné. Les vidéos démarrent muettes ; le son peut être activé volontairement.

Le fond vectoriel nécessite le réseau et un navigateur compatible. En cas d’échec, la carte illustrée prend le relais ; ses distances visuelles sont schématiques, le contrôle de check reste côté serveur. Le GPS réel sur téléphone peut nécessiter HTTPS ; conserver le simulateur pour la répétition locale clairement identifiée.

Pour conserver votre travail avant une mise à jour : arrêter le serveur, sauvegarder le dossier complet avec `.data` et votre `.env`, puis mettre à jour le code sans remplacer ces deux éléments. Aucun reset n’est nécessaire. Ne jamais envoyer vos mots de passe dans une conversation.
